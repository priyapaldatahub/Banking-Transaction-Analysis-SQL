# Entity Relationship Diagram

## Overview

The Entity Relationship (ER) Diagram illustrates the database structure of the **Banking Transaction Analysis** project.

It shows the relationships between the nine tables, including primary keys and foreign keys, providing a clear view of the relational database design.

## Tables Included

- Customers
- Accounts
- Transactions
- Loans
- Loan_Payments
- Cards
- Branches
- Employees
- Support_Tickets

**Purpose:** The ER diagram helps visualize the database schema and understand how the tables are connected to support SQL queries and business analysis.
