# Dataset

## Overview
This folder contains the datasets used for the **Banking Transaction Analysis using SQL** project.

The data was imported into MySQL and used for database creation, data validation, SQL queries, views, stored procedures, triggers, window functions, and business analysis.

## Files Included

| File Name | Description |
|-----------|-------------|
| customers.csv | Customer information |
| accounts.csv | Bank account details |
| transactions_100k.csv | Sample transaction dataset (100,000 records) |
| loans.csv | Customer loan information |
| cards.csv | Debit/Credit card details |
| branches.csv | Bank branch information |
| employees.csv | Employee details |
| support_tickets.csv | Customer support ticket data |

## Notes

- The original project contained a much larger **Transactions** dataset.
- For this GitHub repository, a **100,000-row sample (`transactions_100k.csv`)** is included to keep the repository lightweight and easy to download.
- The original **loan_payments.csv** dataset is not included because it exceeds GitHub's web upload size limit.
- All SQL scripts in this repository are compatible with the original dataset structure.
